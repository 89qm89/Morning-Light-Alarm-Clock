# 晨光闹钟

一款专为 Windows 11 桌面设计的个性化闹钟。它不是简单弹窗，而是带有完整界面、桌面悬浮小组件、多闹钟管理和响铃交互的桌面应用。

## 主要功能

- Win11 风格玻璃拟态界面与实时数字时钟
- 普通窗口、窗口置顶、桌面悬浮小组件三种显示方式
- 多个闹钟，支持单次、每天、工作日、周末和自定义星期
- 闹钟名称、三种铃声、稍后提醒
- 独立响铃窗口，即使主窗口隐藏也会出现
- 开机自动启动、托盘运行、本地保存
- 安装版自动检查、下载并覆盖安装新版本
- 支持 Windows 安装版和绿色便携版

## 直接运行

需要安装 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

## 打包 Windows EXE

在 Windows PowerShell 中运行：

```powershell
npm install
npm run dist:win
```

打包完成后，在 `release` 文件夹可以找到安装版和便携版 `.exe`。

也可以把项目上传到 GitHub，进入 **Actions → Build Windows App → Run workflow**。构建完成后，在该次运行页面的 **Artifacts** 中下载 `晨光闹钟-Windows`。

## 使用提示

- 从 v1.3.0 起，安装版会自动检查更新；下载完成后点击“更新并重启”即可覆盖旧版本。
- 从旧版本升级到 v1.3.0 时需要最后手动安装一次，之后的新版本无需再手动下载安装包。
- 覆盖安装不会删除闹钟、主题颜色、开机启动等本机设置。
- 便携版不执行自动覆盖安装，可在软件内前往发布页下载新版。
- 点击右上角的小组件按钮，可切换为桌面悬浮模式。
- 悬浮模式会自动靠近屏幕右下角，并保持置顶。
- 点击托盘图标可以重新显示主窗口。
- 关闭主窗口后程序仍会在托盘运行，以保证闹钟正常响铃；在托盘菜单选择“彻底退出”才会退出。

所有闹钟数据只保存在本机，不会上传到网络。
