# 晨光闹钟版本更新记录

## 1.3.0

### 本版简介

本次更新加入安装版自动更新。以后发现新版本后，软件会自动下载，并在用户确认后直接覆盖旧版本，无需先卸载，也不会清除闹钟和设置。

### 新增

- 安装版启动后会自动检查 GitHub 正式版本，并每隔一段时间再次检查。
- 新版本会在后台下载，界面显示下载进度。
- 下载完成后可点击“更新并重启”，静默覆盖旧版本并重新打开晨光闹钟。
- 发布流程会同步上传 `latest.yml` 更新元数据，并校验安装包完整性。

### 修改

- 原“前往更新页面”按钮升级为“检查更新 / 下载进度 / 更新并重启”的完整交互。
- 明确保留当前用户的闹钟数据、主题颜色、开机启动等本机设置。
- Windows 安装程序固定采用当前用户安装模式，保证后续版本在原位置完成升级。

### 修复

- 减少每次升级都要手动卸载旧软件、整理下载目录中安装包的麻烦。

### 移除

- 安装版不再把浏览器下载页面作为主要更新方式；便携版仍保留手动下载入口。

## 1.2.1

### 本版简介

本次更新采用用户选定的金蓝磨砂时钟图标，并为自动发布加入清晰、固定格式的版本说明。

### 新增

- GitHub 发布页现在会自动显示本版简介、新增、修改、修复和移除内容。
- 新增版本更新记录校验；以后发布新版本时必须填写对应版本的说明。

### 修改

- 更换安装包、桌面快捷方式、开始菜单、应用窗口和系统托盘所使用的图标。
- 新图标采用深色圆角底座、金色表盘、蓝色层叠下半圆和磨砂质感。

### 修复

- 修复自动发布页只能显示通用说明、无法准确说明本版变化的问题。

### 移除

- 移除上一版不符合预期的图标方案。
